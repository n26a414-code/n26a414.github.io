MP3変換ツール

GitHub Pagesの画面から、同じWi-Fi内のWindows PCで処理します。

① PCサーバーへの接続設定
未接続

同じWi-Fiに接続した状態で使用してください。PC側のPythonサーバーを起動しておく必要があります。

② 変換設定
空欄の場合はPC側の初期保存先（Music\MP3）を使います。
③ 進行状況
待機中
ログ
準備完了。まずPCサーバーへの接続テストをしてください。

Androidではダウンロード後、ブラウザのダウンロード通知や「ダウンロード」フォルダから保存したMP3を確認できます。ブラウザだけで任意の内部フォルダを直接指定できるとは限りません。
